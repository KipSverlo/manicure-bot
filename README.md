# 💅 Nail Studio — демо Telegram-бот

Демо-бот для вымышленного маникюрного салона **Nail Studio** (мастер Алина, работает на дому).
Написан на Python с использованием [aiogram 3.x](https://docs.aiogram.dev/).

## Возможности

- `/start` — приветствие и главное меню:
  - **💅 Услуги и цены** — список услуг с ценами;
  - **📅 Записаться** — пошаговый диалог: имя → услуга → дата/время;
  - **📞 Контакты** — контактная информация мастера.
- Готовая заявка отправляется владельцу в отдельный чат (`OWNER_CHAT_ID`).
- Клиент получает подтверждение: *«Спасибо, [Имя]! Заявка на [Услуга] на [Дата] принята. Алина свяжется с вами для подтверждения»*.
- `/cancel` или кнопка **❌ Отмена** — прервать запись на любом шаге.
- `/myid` — служебная команда, показывает ID текущего чата.
- Ошибки записываются в файл `errors.log`.

## Установка

1. Установите **Python 3.10+** с [python.org](https://www.python.org/downloads/)
   (при установке на Windows отметьте галочку *Add Python to PATH*).

2. Откройте терминал в папке проекта и создайте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

3. Активируйте его:

   - Windows (PowerShell): `venv\Scripts\Activate.ps1`
   - Windows (cmd): `venv\Scripts\activate.bat`
   - macOS / Linux: `source venv/bin/activate`

4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## Настройка

1. Скопируйте `.env.example` в `.env` (если `.env` ещё нет).
2. Укажите токен бота, полученный у [@BotFather](https://t.me/BotFather):

   ```
   BOT_TOKEN=123456789:ABC...
   ```

3. Узнайте ID чата владельца:
   - запустите бота (см. ниже), даже с пустым `OWNER_CHAT_ID`;
   - напишите боту `/myid` из аккаунта владельца — бот пришлёт число;
   - для группы: добавьте бота в группу и отправьте `/myid` там (ID группы начинается с `-`).

4. Впишите ID в `.env` и перезапустите бота:

   ```
   OWNER_CHAT_ID=123456789
   ```

> ⚠️ Владелец должен хотя бы один раз нажать **Start** в боте — иначе Telegram не позволит боту написать ему первым.

## Запуск

```bash
python bot.py
```

Остановить бота — `Ctrl+C`.

## Логи

- Информационные сообщения выводятся в консоль.
- Ошибки (уровень ERROR и выше) пишутся в `errors.log` рядом с `bot.py`.

## Как изменить услуги и цены

Отредактируйте словарь `SERVICES` в начале файла `bot.py`:

```python
SERVICES = {
    "Маникюр классический": 1500,
    "Покрытие гель-лак": 2000,
    "Наращивание": 3000,
}
```

Кнопки выбора услуги при записи сформируются автоматически.

## Ограничения демо-версии

- Состояния диалога хранятся в памяти (`MemoryStorage`) — при перезапуске незавершённые записи сбрасываются.
- Дата и время вводятся свободным текстом, без проверки формата и занятости.
